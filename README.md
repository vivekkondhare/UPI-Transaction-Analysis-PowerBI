# UPI-Transaction-Analysis-PowerBI
Interactive Power BI dashboard for analyzing UPI transaction trends, transaction performance, payment methods, customer demographics and transaction status for 2024
Business Questions

For example:

What are the monthly transaction trends during 2024?
What proportion of transactions were successful vs. failed?
Which payment methods were used most frequently?
How do transaction patterns vary across cities?
Which transaction types contribute most to transaction volume?
How do customer demographics relate to transaction activity?
How does the transaction balance change over time?
