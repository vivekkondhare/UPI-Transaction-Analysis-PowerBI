# UPI-Transaction-Analysis-PowerBI
Interactive Power BI dashboard for analyzing UPI transaction trends, transaction performance, payment methods, customer demographics and transaction status for 2024


The dashboard provides interactive analysis using filters such as:

- Bank Name Sent
- Bank Name Received
- City
- Device Type
- Gender
- Age Group
- Merchant Name
- Payment Method
- Purpose
- Transaction Type

The dashboard also includes monthly transaction analysis for January–December 2024 and city/currency-level transaction and remaining-balance analysis.
